# AH Bouquets

Static, GitHub Pages-ready landing page for AH Bouquets.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose main and the root folder.
4. Save. GitHub will provide the live website address in a minute or two.

## Included

- index.html — the complete landing page
- hero-bouquet.png — transparent bouquet hero image

Keep hero-bouquet.png in the same top-level repository folder as index.html. The hero asset is loaded as a normal local PNG, so it retains transparency and scales without a gray box.
